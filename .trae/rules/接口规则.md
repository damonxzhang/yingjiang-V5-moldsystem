除了登录接口，调用其他接口时，调用api 接口时，先 const authData = AuthService.getStoredAuth(); 获取登录人信息，然后判断 authData 是否存在，不存在不存在则抛出异常'未登录或登录已过期'，再判断 authData.department 是否存在，不存在则抛出异常'当前用户未设置部门信息'。代码可以参考如下：
```javascript
  const authData = AuthService.getStoredAuth();
  if (!authData) {
    throw new Error('未登录或登录已过期');
  }

  if (!authData.department) {
    throw new Error('当前用户未设置部门信息');
  }
```
调用接口的headers 中添加Authorization: Bearer ${authData.token}
```javascript
  const response = await fetch(url, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${authData.token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(params)
  });
```
