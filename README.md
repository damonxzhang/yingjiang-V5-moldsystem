# SmartMold 模具管理系统 - V 5.1.20260212.003

SmartMold 是一款专为现代化工厂设计的智能化模具管理与维护平台。系统通过实时监控、数据分析和预测算法，全方位提升模具使用寿命，优化备件库存，确保生产流程的连续性与高效性。

## 核心功能模块

### 1. 数字化监控大屏 (Dashboard)
- **设备生产看板 (主入口)**：实时展示全厂 24 台设备（BMD-01 ~ BMD-24）的生产状态。每台设备支持 3 模（P1/P2/P3）模式监控，直观显示当前批次（LOT）生产进度。
- **状态预警体系**：通过边框颜色（绿、黄、红、蓝）实时区分设备状态（正常、即将保养、超期、BUYOFF）。
- **看板说明系统**：内置交互式图例，详细说明状态颜色、图标角标及进度条含义。

### 2. 生产准备与实时监控
- **可生产产品 LIST**：根据模具实时健康状态，动态计算并筛选当前可投入生产的产品清单。
- **实时 Shot 数监控**：实时采集模具冲次数据，通过动态曲线监控模具损耗趋势。

### 3. 模具全生命周期管理
- **模具台账与绑定**：建立数字化档案，支持模具与备件的 BOM 级对应关系绑定。
- **任务中心**：集中化管理保养、点检、维修任务。
- **执行记录追溯**：完整的保养与维修执行日志，支持全生命周期追溯。

### 4. 备件管理与智能预测
- **备件管理系统**：精准控制备件库存水位。
- **备件购买预测**：**（核心特色）** 支持上传 Excel 排产计划，结合模具当前寿命与消耗规律，智能生成未来采买清单，彻底消除停工待料风险。

## V 5.1.20260212.003 更新要点
- **筛选增强**：新增“显示异常生产设备”复选框，一键定位需要关注的设备。
- **视觉优化**：加粗了模具寿命进度条（60%变黄，90%变红并增加发光效果），加粗了看板卡片边框。
- **交互说明**：完善了看板说明弹窗，增加了所有进度条的详细定义说明。
- **边框修复**：解决了筛选后看板卡片边框厚度不一致的问题。

## 技术特性
- **技术栈**：React + TypeScript + Tailwind CSS + Vite。
- **现代化 UI**：专为工业大屏设计的深色主题（Dark Mode），高对比度视觉反馈。
- **响应式设计**：适配管理后台与大屏显示。

## 快速开始

### 开发环境配置
1. **安装依赖**：
   ```bash
   npm install
   ```
2. **启动项目**：
   ```bash
   npm run dev
   ```
3. **访问地址**：默认访问 [http://localhost:3000](http://localhost:3000)（如端口占用会自动切换）。
