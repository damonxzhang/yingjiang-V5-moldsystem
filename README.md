# SmartMold 模具管理系统 - V 5.1.20260305.002

SmartMold 是一款专为现代化工厂设计的智能化模具管理与维护平台。系统通过实时监控、数据分析和预测算法，全方位提升模具使用寿命，优化备件库存，确保生产流程的连续性与高效性。

## 核心功能模块

### 1. 数字化监控大屏 (Dashboard)
- **设备生产看板 (主入口)**：实时展示全厂 24 台设备（BMD-01 ~ BMD-24）的生产状态。每台设备根据实际配置动态支持 **2模、3模或4模** 监控模式，界面布局自动适配。
- **状态预警体系**：通过边框颜色（绿、黄、红、蓝、灰）实时区分设备状态（正常、即将保养、超期、BUYOFF、已停用）。
- **看板说明系统**：内置交互式图例，详细说明状态颜色、图标角标及进度条含义。

### 2. 生产准备与实时监控
- **可生产产品 LIST**：根据模具实时健康状态，动态计算并筛选当前可投入生产的产品清单。
- **实时 Shot 数监控**：实时采集模具冲次数据，通过动态曲线监控模具损耗趋势。
- **库存模具可视化**：在安装清单中提供模具的实时状态追踪（闲置中、使用中、维修中），并支持显示存放柜号或所在设备号。

### 3. 模具全生命周期管理 (多部门协同)
- **模具台账与拆分**：支持按 **大材料/小材料** 部门独立管理模具台账。新增模具简名、厚度、分类、产品类型等专业化字段。
- **SHOT 上限管理**：在模具台账中新增 SHOT 上限列，直观对比实时冲次与寿命极限。
- **模具停用流程**：支持对报废或长期闲置模具进行“停用”操作，自动在生产看板与安装清单中移除。
- **模具配件绑定**：**（新）** 提供模具与备件的关联绑定功能，实现维保时备件消耗的精准追踪。
- **维保标准作业维护 (CRUD)**：新增保养选项与维修选项的后台维护页面，支持对标准作业内容进行分类管理（常规、电气、机械等）。
- **任务中心**：集中化管理保养、点检、维修任务。
- **执行记录追溯**：完整的保养与维修执行日志，支持全生命周期追溯。

### 4. 备件管理与智能预测
- **部门化备件管理**：备件库存按部门（大材料/小材料）进行隔离管理，支持精准的库存水位控制。
- **备件购买预测**：**（核心特色）** 支持上传 Excel 排产计划，结合模具当前寿命与消耗规律，智能生成未来采买清单，彻底消除停工待料风险。

### 5. 系统权限管理 (RBAC)
- **角色体系调整**：系统角色全面升级为 5 类核心角色：
  - **管理员**：拥有系统全模块操作权限。
  - **大材料工程师**：专注于大材料模具及备件的全生命周期管理。
  - **小材料工程师**：专注于小材料模具及备件的全生命周期管理。
  - **带班**：负责现场任务分配、确认及执行监控。
  - **操作员**：负责现场模具查询、转换及基础执行反馈。
- **用户账号管理**：支持用户信息的增删改查，自动生成用户 ID，并可灵活分配所属部门与角色状态。
